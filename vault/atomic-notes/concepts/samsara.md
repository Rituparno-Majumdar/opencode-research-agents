# Samsara

The endless cycle of birth, death, and rebirth that souls experience until liberation.

## Causal Links (A → B)
- [[samsara]] → [[moksha]] — the goal is to escape this cycle

## Effect Links (A ← B)
- [[karma]] ← [[samsara]] — actions in the cycle create future rebirths
- [[anatta]] ← [[samsara]] — no permanent self exists within the cycle

## Symmetric Links (A ↔ B)
- [[samsara]] ↔ [[bardo]] — death and rebirth are transitional phases
