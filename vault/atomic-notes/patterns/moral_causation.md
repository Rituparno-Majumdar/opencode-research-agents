# Moral Causation Across Traditions

Different traditions explain the connection between action and consequence in different ways. This pattern traces these variations.

## Causal Links (A → B)
- [[karma]] → [[rebirth]] — Indic: action determines next birth
- [[moira]] → [[fate]] — Greek: externally decreed destiny
- [[maat]] → [[judgment]] — Egyptian: cosmic order weighs at death

## Effect Links (A ← B)
- [[free_will]] ← [[karma]] — Tension: does karma constrain choice?
- [[justice]] ← [[karma]] — Does cosmic justice require rebirth?

## Symmetric Links (A ↔ B)
- [[stoic_logos]] ↔ [[prakriti]] — both are immanent rational principles
- [[schopenhauer_will]] ↔ [[atman]] — both are metaphysical ground, different evaluations
- [[buddhist_dependent_origination]] ↔ [[stoic_determinism]] — both deny random chance

## Cross-Tradition Notes
The Indic karma system is unique in combining: (1) individual moral agency, (2) cosmic law, (3) rebirth mechanism. Other traditions have partial parallels but lack this combination.
