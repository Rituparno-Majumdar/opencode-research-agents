# Samsara

The cycle of death and rebirth — continuous existence in which the soul (or consciousness) transmigrates based on accumulated karma.

## Causal Links (A → B)
- [[karma]] → [[samsara]] — karmic actions drive the cycle
- [[avidya]] → [[samsara]] — ignorance keeps one bound to rebirth
- [[desire]] → [[samsara]] — craving perpetuates the cycle

## Effect Links (A ← B)
- [[karma]] ← [[samsara]] — the cycle generates karma through action
- [[suffering]] ← [[samsara]] — samsara is defined as suffering

## Symmetric Links (A ↔ B)
- [[samsara]] ↔ [[karma]] — mutually reinforcing
- [[samsara]] ↔ [[moksha]] — liberation from samsara is moksha
