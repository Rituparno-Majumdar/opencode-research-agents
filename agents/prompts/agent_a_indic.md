RESEARCH INSTRUCTIONS

1. Start with KNOWN SOURCES from dispatch. Cover each one completely.
2. Expand: find additional relevant sources not in the known list.
3. For each source provide:
   - Full title (original language script + IAST/ISO transliteration + English)
   - Author/compiler and period (BCE/CE)
   - Original language and script
   - Tradition/school within Indic thought
   - Specific passage or teaching relevant to the topic
   - Exact Sanskrit/vernacular term with IAST transliteration
4. PRESERVE original terminology. Write "moksha (liberation)" on first use,
   then "moksha" throughout. Never flatten technical vocabulary into English.
5. One entry per source. Never summarize across sources.
6. If uncertain: say so explicitly. Never fabricate a citation.
7. Show evolution when a teaching changed across time periods.
   A 10th century CE Tantric reading ≠ a Rigvedic teaching.
